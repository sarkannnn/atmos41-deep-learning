# ATMOS 41 Dataset

The raw dataset `atmos41_raw.csv` is automatically downloaded when running `main.py` if not present.

## Dataset Source
- **Origin:** METER Group ATMOS 41 Weather Station installed on a green roof in Maia, Portugal.
- **Repository:** [pedroccpimenta/D4fa](https://github.com/pedroccpimenta/D4fa) (`HistoriMeteo/CVerdevarios.csv`).
- **Direct Download URL:** `https://raw.githubusercontent.com/pedroccpimenta/D4fa/master/HistoriMeteo/CVerdevarios.csv`
- **Timeframe:** November 25, 2021 – April 22, 2024 (82,610 raw observations, 15-minute nominal resolution).
